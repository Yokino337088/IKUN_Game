## 二、带动画角色的适配方案

### 2.1 当前架构限制

当前的 [PerformanceCharacter.cs](../Scripts/剧情演出/PerformanceCharacter.cs) 仅支持：
- `SpriteRenderer` 显隐控制
- Sprite 切换（`SetExpression`）
- 位置移动（`MoveTo`）
- 震动效果（`Shake`）

如果角色使用 **Animator** 驱动动画，需要进行以下修改：

### 2.2 方案一：Animator动画控制（推荐）

当角色预制体包含 `Animator` 组件时，需要修改 `PerformanceCharacter.cs` 添加动画播放支持。

#### 2.2.1 需要修改的代码

**修改文件**: [PerformanceCharacter.cs](../Scripts/剧情演出/PerformanceCharacter.cs)

**需要添加的字段**:

```csharp
/// <summary>角色动画器映射表（角色名 → Animator）</summary>
private Dictionary<string, Animator> characterAnimatorMap = new Dictionary<string, Animator>();
```

**需要修改的方法**:

1. **Awake()** - 添加Animator注册：
```csharp
// 在SpriteRenderer注册后添加
foreach (var go in characterPrefabs)
{
    if (go == null) continue;
    var animator = go.GetComponent<Animator>();
    if (animator != null)
        characterAnimatorMap[go.name] = animator;
}
```

2. **RegisterCharacter()** - 添加Animator注册：
```csharp
var animator = characterGO.GetComponent<Animator>();
if (animator != null)
    characterAnimatorMap[name] = animator;
```

3. **添加新方法 PlayAnimation()**:
```csharp
/// <summary>播放角色动画</summary>
/// <param name="name">角色名</param>
/// <param name="animationName">动画状态名</param>
public void PlayAnimation(string name, string animationName)
{
    if (!characterAnimatorMap.TryGetValue(name, out var animator))
    {
        LogSystem.Debug($"PerformanceCharacter: 角色 [{name}] 没有Animator组件");
        return;
    }
    
    animator.Play(animationName);
}
```

4. **添加新方法 SetAnimationTrigger()**:
```csharp
/// <summary>触发角色动画触发器</summary>
public void SetAnimationTrigger(string name, string triggerName)
{
    if (!characterAnimatorMap.TryGetValue(name, out var animator))
    {
        LogSystem.Debug($"PerformanceCharacter: 角色 [{name}] 没有Animator组件");
        return;
    }
    
    animator.SetTrigger(triggerName);
}
```

5. **添加新方法 SetAnimationParameter()**:
```csharp
/// <summary>设置角色动画参数</summary>
public void SetAnimationParameter(string name, string paramName, float value)
{
    if (!characterAnimatorMap.TryGetValue(name, out var animator))
    {
        LogSystem.Debug($"PerformanceCharacter: 角色 [{name}] 没有Animator组件");
        return;
    }
    
    animator.SetFloat(paramName, value);
}
```

#### 2.2.2 演出命令扩展

需要在 [EPerformanceCommandType.cs](../Scripts/剧情演出/EPerformanceCommandType.cs) 中添加新命令类型：

```csharp
[InspectorName("🎭 角色动画 — CharacterAnimation")]
CharacterAnimation,
```

在 [PerformanceCommand.cs](../Scripts/剧情演出/PerformanceCommand.cs) 中添加动画相关字段：

```csharp
[Tooltip("动画状态名（用于Animator.Play）")]
public string animationName;

[Tooltip("动画触发器名（用于Animator.SetTrigger）")]
public string animationTrigger;

[Tooltip("动画参数名（用于Animator.SetFloat）")]
public string animationParamName;

[Tooltip("动画参数值")]
public float animationParamValue;
```

在 [PerformanceDirector.cs](../Scripts/剧情演出/PerformanceDirector.cs) 中添加执行逻辑：

```csharp
case EPerformanceCommandType.CharacterAnimation:
    await ExecuteCharacterAnimation(cmd, ct);
    break;
```

```csharp
private async UniTask ExecuteCharacterAnimation(PerformanceCommand cmd, CancellationToken ct)
{
    if (characterController == null) return;
    
    if (!string.IsNullOrEmpty(cmd.animationTrigger))
    {
        characterController.SetAnimationTrigger(cmd.characterName, cmd.animationTrigger);
    }
    else if (!string.IsNullOrEmpty(cmd.animationParamName))
    {
        characterController.SetAnimationParameter(cmd.characterName, cmd.animationParamName, cmd.animationParamValue);
    }
    else if (!string.IsNullOrEmpty(cmd.animationName))
    {
        characterController.PlayAnimation(cmd.characterName, cmd.animationName);
    }
    
    if (cmd.duration > 0f)
        await UniTask.WaitForSeconds(cmd.duration, cancellationToken: ct);
}
```

### 2.3 方案二：混合模式（Sprite + 动画）

如果部分表情用Sprite切换，部分用动画，可以保留原有逻辑：

- `SetExpression` → 切换Sprite（静态表情）
- `PlayAnimation` → 播放动画（动态动作）

在演出命令中按需选择使用。

### 2.4 角色预制体规范

带动画的角色预制体需要遵循以下结构：

```
爱坤_角色预制体
├── Transform
├── SpriteRenderer (或 SpriteRenderer + Animator)
├── Animator (可选，带动画时添加)
│   └── AnimatorController (包含所有演出动画状态)
└── 其他组件（Collider等）
```

#### Animator状态机建议

为第四章演出，建议Animator包含以下状态：

| 状态名 | 用途 | 触发方式 |
|---|---|---|
| `Idle_Float` | 水下漂浮待机 | Play("Idle_Float") |
| `Fall_Free` | 自由坠落 | Play("Fall_Free") |
| `Lie_Down` | 躺卧 | Play("Lie_Down") |
| `Sit_Up` | 坐起 | Play("Sit_Up") |
| `Stand_Up` | 站立 | Play("Stand_Up") |
| `Shake_Heavy` | 剧烈震动 | Trigger("Shake") |

## 四、注意事项

1. **AB包名称必须严格匹配**：`chapter_four`、`music_four`、`sound_four`
2. **资源名必须严格匹配**：演出命令中的资源名与AB包中的资源名必须一致
3. **动画状态名必须匹配**：Animator中的状态名与演出命令中的`animationName`必须一致
4. **角色名约定**：演出中角色名固定为 `爱坤`，预制体注册时使用此名称
5. **SpriteRenderer层级**：背景层级设置为0，角色层级设置为10，确保正确的渲染顺序
6. **UI层级**：UI画布层级应高于角色，确保对话文字显示在最上层
